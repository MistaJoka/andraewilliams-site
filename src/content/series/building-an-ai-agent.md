Most agent tutorials stop at the loop: call the model, parse a tool call,
run it, feed the result back. That part takes an afternoon. The other
eight parts are what separates a demo from something you'd leave running.

This series follows one agent from an empty file to a system with real
memory, real evaluation, and real failure handling — including the parts
that broke.
