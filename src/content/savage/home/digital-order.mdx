## What it looks like

The savage runs the 3-2-1 rule without exception: three copies of every file that matters, on two different media, one of them off-site. Backups run automatically, and they are tested — a real restore of a real file — at least quarterly. Nothing important lives only on one device or only in one cloud account.

Every account has a unique, generated password held in a password manager. The manager itself is protected by a long passphrase and hardware or app-based two-factor authentication. Two-factor is on everywhere it is offered, with email, banking, and the password manager first. Recovery codes are printed and filed with the documents (HME·04). There is no password that has ever been reused.

Files are ordered. One folder structure, consistent naming, no "final_v3_REAL". The desktop is empty. Downloads are cleared weekly. Any file from the last five years can be found by name in under a minute. Photos are deduplicated, dated, and backed up.

Devices are current. Operating systems and applications are updated within a week of release. Full-disk encryption is on. Screens lock in under two minutes. Every device can be located and remotely wiped. Old devices are wiped before they leave the house. Every device could be lost today and replaced tomorrow with everything restored.

## The gap

The gap looks like "I've been meaning to set up backups." It looks like one password with a number on the end for everything. It looks like a phone with 30,000 photos and no copy anywhere else. It looks like a desktop of two hundred icons. It looks like a laptop three major versions behind because updating is inconvenient. It looks like finding out the backup did not work on the day it was needed.

## How to get there

- Password manager first. Migrate every account over one session at a time, generating a new password for each. Enable two-factor as you go.
- Set automatic backups to a local drive and a cloud service today. Put a quarterly restore test in the calendar (HME·03).
- Adopt one folder tree and one naming convention. Spend one weekend migrating; then never deviate.
- Turn on automatic updates, full-disk encryption, and remote locate-and-wipe on every device.
- Annual digital audit: delete dead accounts, rotate critical passwords, verify recovery codes, check who has access to shared drives.

## Measures

- Last successful restore test: dated, within ninety days.
- Reused passwords in the password manager's audit: zero. Accounts without two-factor where available: zero.
- Any file from the last five years found by name in under sixty seconds, timed.
- All devices: encryption on, OS current within one release, remote wipe enabled. Checked, dated.
- Desktop and downloads folder: empty at the end of the weekly reset.

## Canon

- **Data and Goliath**, Bruce Schneier — the case for why encryption, backups, and personal digital infrastructure are not optional.
- **The Practice of System and Network Administration**, Thomas Limoncelli, Christina Hogan & Strata Chalup — the professional playbook for backups and naming discipline, applied at home scale.
- **Ghost in the Wires**, Kevin Mitnick — a first-hand account of exactly what unique passwords and two-factor authentication are defending against.
